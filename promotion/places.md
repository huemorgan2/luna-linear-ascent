# Places to list Linear Ascent

A map of directories, stores, creator platforms, and YouTuber inboxes that fit a **free browser shared-world RPG**. Destination for every listing: https://linearascent.net (play at `/play`).

Copy lives in [listing-sheet.md](listing-sheet.md). Status of each attempt is in [tracker.md](tracker.md). YouTuber-specific outreach is in [youtuber-outreach.md](youtuber-outreach.md).

Fit key: **yes** = this audience matches. **maybe** = worth a listing, weak traffic or extra work. **no** = skip unless the game changes (Steam, HTML5 iframe portal, cozy, etc.).

---

## A. Stores and long-tail directories (YouTubers browse these)

| Place | Submit | Fit | Notes |
|---|---|---|---|
| [itch.io](https://itch.io/game/new) | Account + game page. Link out to linearascent.net or embed web play. | yes | First store page most indie YouTubers check. Devlogs help. |
| [IndieDB](https://www.indiedb.com/games/add) | Account + add game. | yes | Long-tail SEO. Update with news or it dies. |
| [Game Jolt](https://gamejolt.com/dashboard/games/add) | Account + add game. | yes | Community + YouTubers still scrape it for free games. |
| [GameHubber](https://gamehubber.com/en/developers) | Submit / claim a game. | yes | Upcoming + live discovery. Players tracking new games. |
| [IndieVault](https://indievault.io/auth?tab=signup&role=creator) | Creator signup, then publish. | yes | Indie browse directory. |
| [IFDB](https://ifdb.org/) | Account + create listing. | maybe | Interactive-fiction crowd. Pitch as a live multiplayer game, not a single-player text adventure. |
| [AlternativeTo](https://alternativeto.net/) | Suggest as alternative to LORD, Kingdom of Loathing, Fallen London, AI Dungeon. | maybe | SEO, not players. |
| Steam | Steamworks. | no | No Steam build. Add when/if a store page exists. |
| GOG / Epic / Nintendo | Store portals. | no | Same. |

## C. Creator / YouTuber platforms (they come to you)

These are the actual “YouTuber places”: creators browse a catalog and request a key or a play link.

| Place | Submit | Fit | Notes |
|---|---|---|---|
| [Keymailer / Partnier](https://keymailer.co/publisher/) | Publisher signup. List the game. Creators request access. | yes | Biggest inbound YouTuber catalog. Free trial. No Steam keys — list a free play URL. |
| [PlayIndies](https://playindies.com/) | Join as developer. Manual verify. | yes | Curated indie ↔ creator matchmaking. |
| [Gamosy](https://gamosy.com/) | Developer campaign. | yes | Key distribution + YouTube/Twitch/TikTok verify. Use play-link instead of Steam keys. |
| [Key Lynx](https://keylynx.gg/) | List game. Free tier: 1 game. | yes | Indie-sized. Creators request from you. |
| [Game.Press](https://keymailer.co/publisher/) | Via Keymailer. | maybe | Press + influencer portal. |
| Lurkit / WhooVit | Paid creator marketplaces. | maybe | Skip until there is budget. |
| [Alpha Beta Gamer](https://www.alphabetagamer.com/contact-us/) | Email admin@alphabetagamer.com + Discord. | yes | ~800k-sub YouTube that covers overlooked indies. **Wants free public play.** Exact fit. |
| Product Hunt | Ship a product, not a game store. | maybe | Angle: “an MMO that plays in a chat window.” Tech audience, one-day spike. |

| r/playmygame | yes | Read rules. Feedback-first. |
